# Masalah umum

## Perangkat tidak menyebutkan kode

- Pastikan WiFi sudah tersambung — perangkat butuh internet untuk meminta kode.
- Tekan tombol **sebentar** untuk mengulang pengumuman.
- Jika tetap hening, perangkat mungkin gagal menghubungi server. Ia akan otomatis
  beralih ke **mode setup lokal**: ikuti petunjuk suara untuk membuka alamat lokal
  (`aural-xxxx.local`) di WiFi yang sama.

## Kode ditolak / "kode tidak valid"

- Kode **kedaluwarsa dalam 10 menit** dan hanya bisa dipakai sekali. Minta kode
  baru dengan menekan tombol perangkat **sebentar**.
- Periksa kembali ejaan. Huruf yang mirip (seperti 0 dan O) sudah dihindari pada kode.

## Layanan AI tidak bekerja

- Pastikan API key benar dan masih punya kuota di penyedia layanan.
- Coba uji koneksi dari halaman [Perangkat saya](/dashboard).
- Deteksi objek dasar tetap bekerja tanpa AI — ini hanya memengaruhi
  "Deskripsi pemandangan" dan QRIS online.

## Perangkat tampil "Terputus"

- Cek apakah perangkat masih menyala dan dalam jangkauan WiFi.
- Perangkat mengirim "denyut" status berkala; jeda beberapa detik adalah normal.
- Mati listrik atau WiFi putus akan menampilkan status terputus sampai ia kembali online.

## Tetap perlu bantuan?

Perangkat **selalu bisa bekerja offline** untuk fungsi inti. Web ini hanya untuk
setup dan pemantauan, jadi kendala jaringan di sini tidak menghentikan perangkat
mengenali objek dan berbicara.
