# Merakit & menyalakan

## Menyalakan

1. Pasang modul AuralAI pada tangkai kanan kacamata.
2. Tekan tombol **Power** sampai LED hijau menyala.
3. Tunggu beberapa saat — saat siap, perangkat akan mengucapkan **"AuralAI siap digunakan."**

## Menyambungkan ke WiFi

Perangkat perlu terhubung ke WiFi rumah agar bisa di-pair lewat web dan memakai
layanan AI. WiFi diatur **secara lokal** (langkah ini tidak bisa lewat internet,
karena perangkat belum online):

1. Pada saat pertama kali, perangkat membuka halaman pengaturan lokal.
   Ikuti suara yang dipandu perangkat untuk menyambungkan WiFi.
2. Masukkan **nama jaringan (SSID)** dan **password** WiFi rumahmu.
3. Setelah tersambung, perangkat akan otomatis lanjut ke tahap **pairing** dan
   menyebutkan kode unik.

> Gunakan WiFi **2,4 GHz**. Banyak perangkat hemat-daya tidak mendukung 5 GHz.

## Tombol

Perangkat hanya punya satu tombol, dengan dua jenis tekanan:

| Tekanan | Saat setup | Setelah terhubung |
| --- | --- | --- |
| **Sebentar** (< 1 detik) | Ulangi kode/petunjuk yang diucapkan | Ganti mode (Jelajah → Deskripsi → QRIS) |
| **Agak lama** (≥ 1 detik) | Tandai "sudah paham" (berhenti mengulang) | Ucapkan ulang petunjuk koneksi |
