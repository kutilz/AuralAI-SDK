Volume suara

Volume—

Atur kenyaringan suara perangkat (0–100). Berlaku langsung.

Tahan tombol MODE + ACTION bersamaan ±1 detik untuk masuk mode volume. Setelah itu MODE mengecilkan, ACTION membesarkan — tiap langkah dibunyikan pada volume barunya, jadi kenyaringan langsung terdengar. Mode menutup sendiri setelah beberapa detik diam. Lewat tombol, volume tidak bisa turun sampai bisu; itu hanya dari halaman ini.

Suara pembaca

Tekan sebuah suara untuk mendengarkan contohnya — belum tersimpan. Tekan Pakai suara ini untuk menyimpan.

Mode saat perangkat dinyalakan

Diam: perangkat menyala, terhubung, tapi belum mengamati apa pun — kamera dilepas, jadi paling dingin dan paling hemat. Tekan tombol MODE untuk mulai. Explorer: langsung mendeteksi begitu menyala.

Setelan teknis — mode suara, latensi & kontrol QA

Mode suara deskripsi

Caching per-kata: kalimat dirangkai dari audio kata yang tersimpan — makin sering dipakai makin instan (nol jaringan), tapi bisa agak patah. Satu blok audio: seluruh kalimat disintesis utuh — paling halus, tapi tiap kali menunggu jaringan.
